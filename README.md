# 📱 SocialBook

A modern social media web application built with **Django** that allows users to connect, share posts, follow others, and interact through likes and comments. SocialBook provides a clean and responsive user experience inspired by popular social networking platforms.

---

## ✨ Features

### 👤 User Authentication

* User registration
* Secure login & logout
* Profile management

### 📝 Posts

* Create posts
* Upload images
* Delete posts
* View posts in a personalized feed

### ❤️ Social Interaction

* Like and unlike posts
* Comment on posts
* Follow and unfollow users
* User profile pages

### 🔍 Discover

* Search users
* View user profiles
* Explore public posts

---

## 🛠️ Tech Stack

* **Backend:** Django (Python)
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite (Development)
* **Authentication:** Django Authentication System
* **Media Storage:** Django Media Files

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/rijogit007/socialbook.git
```

### Navigate into the project

```bash
cd socialbook
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
